# 家庭点菜单 · 使用说明

一个**纯前端**的家庭点菜小工具：手机点开链接就能点菜，家长端实时收到点单。
无需注册、无需服务器后端、无需数据库；菜单改动**自动同步**给所有家人，**二维码长期有效，改菜不用重新分享**。

## 文件

- `index.html` —— 全部功能都在这一个页面里
- `qrcode.min.js` —— 本地二维码组件
- `img/` —— 菜品图片文件夹（把菜的照片按菜名命名放进来即可，见下文）

## 功能

- **分类浏览**：点菜页按分类分组展示，顶部分类按钮点击可快速跳转，滚动时自动高亮当前分类。
- **搜索**：顶部搜索栏按菜名/备注实时过滤。
- **限时菜**：编辑菜品时设置"限时供应"时段（可跨零点，如 21:00–01:00），每天循环；时段外自动灰显"未开始/已结束"，家人不能点，到点自动开放。
- **菜品排序**：管理页每个菜品有 ↑ ↓ 按钮调整位置，点菜页按此顺序显示；改动自动同步给家人。
- **图片**：照片按菜名放进 `img/` 自动显示，或在编辑菜品时填图片网址。

## 怎么用

第一次使用（在做饭的人的手机上）：

1. 打开页面，点右上角 ⚙️ 进入管理。
2. 在「菜单」标签输入菜名快速添加；点「编辑」可设置分类、备注、今日做不做、图片。
3. 点「生成点菜二维码 / 链接」，把链接发到家庭群（或保存二维码图片）。**发一次就够了。**
4. 保持「设置 → 实时同步」开启并显示已连接。之后你每次改菜单，都会自动推送到所有打开过链接的家人手机；家人一点菜，这边立刻弹提醒、有提示音。

家人点菜：

1. 在家庭群点开链接（或扫二维码）。第一次打开会自动下载菜单，之后菜单有改动会自动更新。
2. 选菜、填称呼和备注，点「提交点菜」。
3. 点「复制文字」把点菜消息发到家庭群，家长点开消息里的链接同样能收单（实时通道不可用时的兜底）。

家长看单：⚙️ →「点菜单」，按天分组，可标记"已做好"、"清空今日"。

## 菜品图片（已预留）

三种方式，任选：

1. **零操作（推荐）**：把照片按菜名命名，放进 `img` 文件夹，例如 `img/红烧肉.jpg` 或 `img/红烧肉.png`，页面自动显示，菜单里不用填任何东西。中文名没问题。
2. **填图片网址**：编辑菜品时在"图片"一栏粘贴一个图片链接。
3. 都不弄就显示占位图，完全不影响使用。

## 部署到网上（任何地方都能用，约 5 分钟）

### 快速预览（已有脚本，1 分钟）

本目录附带了两个脚本，可以把页面一键部署成**临时预览链接**（免登录，EdgeOne 匿名部署）：

```
node ../build-single.js    # 生成单文件版 single.html（内联了二维码库）
node ../deploy-edgeone.js  # 部署并打印公开访问链接
```

适合先让全家人立刻试用。但匿名部署是**临时链接**，还带 EdgeOne 的"使用 Pages 部署"角标，不适合当正式二维码——试用满意后，按下面方案一在控制台正式部署一次（把文件夹拖进去即可，永久有效）。

### 方案一（推荐，国内访问快）：腾讯 EdgeOne Pages

1. 打开 [pages.edgeone.ai](https://pages.edgeone.ai)（腾讯 EdgeOne Pages），用腾讯云账号注册/登录（国内用户需登录后才能拿到访问网址）。
2. 选择"拖拽部署"（Pages Drop），把整个 `diancai` 文件夹（含 `img`）拖进去，点部署。
3. 几十秒后得到默认网址（形如 `https://xxx.edgeone.app`，可自定义子域名），手机打开确认能访问。
4. ⚙️ → 设置 → 把这个网址填进"页面网址" → 重新生成二维码发到家庭群。

默认域名国内可直接访问、不需要自己备案；以后只有在改动 `img` 照片时才需要重新拖一次文件夹。

### 方案二（备选）：GitHub Pages

1. 注册/登录 [github.com](https://github.com)，点右上角 + → New repository，名字如 `family-menu`，选 Public，点 Create repository。
2. 在仓库页点 "uploading an existing file"，把 `index.html`、`qrcode.min.js` 拖进去，点 Commit changes。
3. 再点 "Add file → Upload files" 把菜品照片上传到 **`img` 文件夹**（文件名如 `红烧肉.jpg`；上传时在文件名框里输入 `img/红烧肉.jpg` 就会自动建文件夹）。
4. 仓库 Settings → Pages → Branch 选 `main`，Save。一分钟后得到网址：`https://你的用户名.github.io/family-menu/`
5. 手机打开这个网址 → ⚙️ → 设置 → 确认"页面网址"一栏填的就是这个网址 → 重新生成二维码发到家庭群。

GitHub Pages 的缺点是国内访问时快时慢；如果家人反馈打开慢，换方案一即可（两个平台部署的页面功能完全一样）。

> 注意：**Gitee（码云）做不了**——它的 Gitee Pages 静态托管服务从 2024 年中起已停止服务且至今未恢复，别在上面浪费时间。

部署完成。之后改菜单只需在页面上改，**不用重新部署、不用重新分享**（除非改了 img 里的照片才需要重新上传）。

## 只在家里用（可选）

不部署也行：电脑上在 `diancai` 目录运行 `node serve.js`，手机连同一 WiFi 访问 `http://电脑IP:8321`。首次可能被 Windows 防火墙拦截，选"允许访问"。

## 原理说明

- 页面完全静态，托管在任何静态空间都能跑。
- 链接里带一个随机频道号（ntfy.sh 免费公共频道）：菜单每次改动都会发布到频道，所有设备的页面实时监听；新设备打开链接时还会从频道缓存补拉最新菜单。所以二维码长期有效，改菜自动同步。
- 实时通道不可用时，点菜文字里的收单链接是兜底。
- 各设备数据存本地 localStorage，设置里有「复制备份 / 导入备份」用于换机。

## 已知限制

- 菜单同步依赖 ntfy.sh 免费服务（消息缓存约 12 小时）；页面会每 5 小时自动保活。如果家人超过一天没打开页面且期间保活失败，可能出现菜单不是最新的——重新点开家庭群里的链接即可立刻同步。
- 没有支付、没有账号体系——家里用不需要。
